## Descripción del problema
Esta tarea consiste en una aplicación desarrollada en Java . El programa simula el funcionamiento básico de un sistema operativo mediante la representación de una CPU, la memoria principal y los Bloques de Control de Procesos (BCP).

La aplicación permite visualizar las instrucciones almacenadas en memoria, ejecutar el programa paso a paso y observar los cambios en los registros de la CPU y en el estado del proceso.


## Instrucciones de ejecución
1. Debes de tener instalado NetBeans
2. Abrir el proyecto en Netbeans yendo a la ruta /Programa/Tarea-Principios
3. Ejecutar el proyecto con el botón de Run
4. Cargar el archivo .asm con el botón de Cargar archivo
5. Ejecutar paso a paso o ejecutar todo
