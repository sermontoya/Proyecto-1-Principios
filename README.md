## Descripción del problema
Esta tarea consiste en una aplicación desarrollada en Java . El programa simula el funcionamiento básico de un sistema operativo mediante la representación de una CPU, la memoria principal, almacenamiento y los Bloques de Control de Procesos (BCP). Se basa en gestionar los procesos que entren al Sistema Operativo y se deben manejar de manera correcta para utilizar los recursos
